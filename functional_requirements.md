# Functional Requirements

| ID | Requirement |
|---|---|
| FR-01 | The system shall display all available doctors. |
| FR-02 | The system shall accept a problem description from the user. |
| FR-03 | The system shall accept a doctor-search budget. |
| FR-04 | The system shall map supported problem keywords to specializations. |
| FR-05 | The system shall display a doctor when specialization and budget conditions match. |
| FR-06 | The system shall accept patient name and age for booking. |
| FR-07 | The system shall display available doctors during booking. |
| FR-08 | The system shall validate the entered doctor ID. |
| FR-09 | The system shall store appointment details. |
| FR-10 | The system shall display all stored appointments. |
| FR-11 | The system shall cancel an appointment using patient name. |
| FR-12 | The system shall report when an appointment is not found. |
| FR-13 | The system shall exit when the user selects option 6. |

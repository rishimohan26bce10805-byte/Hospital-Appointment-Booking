# Hospital Appointment Booking System

## Introduction

The Hospital Appointment Booking System is a simple Python-based
command-line project that helps users find suitable doctors and book
hospital appointments.

## Features

- View available doctors
- Find a suitable doctor based on the problem
- Check the consultation fee according to the patient's budget
- Book an appointment
- View appointments
- Cancel an appointment

## Technology Used

- Python

## Requirements

- Python 3

## How to Run

1. Download or clone this repository.
2. Open the project folder in Command Prompt or Terminal.
3. Run the following command:

python main.py

## How the System Works

The user can first view the available doctors.

The user can also enter their problem, urgency and budget to find a
suitable doctor.

After selecting a doctor, the user can book an appointment by entering
their name, age, date and time.

The user can also view or cancel an appointment.

## Project Limitations

This is a basic academic project. Appointment information is stored
only while the program is running. The project does not use a database
or external Python modules.

## Conclusion

The project demonstrates basic Python programming concepts such as
lists, functions, loops, conditional statements and user input.
